# 🚗 Road Traffic Accident Dashboard

## 📌 Project Overview
This Power BI dashboard analyzes Road Traffic Accident data from **2021 to 2026**. It provides interactive visualizations to identify accident trends, severity, vehicle types, road types, weather conditions, and provincial accident patterns.

## 📊 Dashboard Features
- Total Accidents KPI
- Fatal Accidents KPI
- Damage Only Accidents KPI
- Average Speed KPI
- Total Drivers KPI
- Monthly Accident Trend
- Accident Severity Distribution
- Province-wise Accident Analysis
- Vehicle Type Analysis
- Road Type Distribution
- Time of Day Analysis
- Weather Condition Analysis
- Interactive Filters (Gender, Year, Province, Vehicle Type, Weather Condition)

## 🛠️ Tools Used
- Power BI Desktop
- Microsoft Excel (Dataset)
- GitHub

## 📈 Dashboard Highlights
- Interactive dashboard with slicers
- KPI Cards for quick insights
- Bar Charts
- Donut Charts
- Dynamic filtering and analysis
